## 一、动态规划概述

### 1.1 起源
- **创始人**：20 世纪 50 年代初，美国数学家 **R.E. Bellman**（贝尔曼）
- 在研究**多阶段决策过程**（multistep decision process）的优化问题时，提出了著名的**最优化原理**（principle of optimality）
- 核心思想：把多阶段过程转化为一系列单阶段问题，逐个求解
- Bellman 也是强化学习的奠基者

### 1.2 应用领域
- 最短路线、库存管理、资源分配、设备更新、排序、装载问题
- 经济管理、生产调度、工程技术和最优控制等

### 1.3 多阶段决策过程
- 问题有 N 个输入，解由 N 个输入的一个子集组成，需满足**约束条件**
- 满足约束的解称为**可行解**，衡量优劣的标准函数称为**目标函数**（评价函数）
- 使目标函数取得极值（极大或极小）的可行解称为**最优解**，这类问题称为**最优化问题**
- 活动过程划分为若干**阶段**，每一阶段的决策依赖前一阶段的状态，决策使状态发生转移

### 1.4 最优性原理（Principle of Optimality）
> **无论过程的初态和初始决策是什么，其余的决策都必须相对于初始决策所产生的状态，构成一个最优决策序列。**

换言之：
- 各子问题的解只与它前面的子问题的解相关
- 各子问题的解都是相对于当前状态的**最优解**
- 整个问题的最优解由各个子问题的最优解构成
- 如果一个问题满足最优性原理，则称此问题具有**最优子结构性质**

**关键**：解决问题的关键在于获取各阶段问题的**递推关系式**（动态规划函数）。

### 1.5 动态规划的核心思想
动态规划将待求解问题分解成若干个**相互重叠**的子问题：
1. **划分子问题**：每个子问题对应一个决策阶段，子问题之间有重叠关系
2. **确定动态规划函数**：根据重叠关系找到递推关系式（这是关键！）
3. **填写表格**：以**自底向上**的方式计算各子问题的解并填表，避免重复计算

> 与分治法对比：分治法的子问题是**相互独立**的；动态规划的子问题是**相互重叠**的。动态规划通过**空间换时间**，将子问题的解存入表格，需要时查表即可。

## 二、动态规划的基本要素

### 2.1 最优子结构（Optimal Substructure）
- 问题的最优解包含着其子问题的最优解，这种性质称为**最优子结构性质**
- **证明方法**（反证法）：假设由问题最优解导出的子问题的解不是最优的 → 构造出比原问题最优解更好的解 → 矛盾
- 最优子结构是问题能用动态规划算法求解的**前提**
- 同一个问题可以有多种方式刻划最优子结构

### 2.2 重叠子问题（Overlapping Subproblems）
- 递归求解时，每次产生的子问题并不总是新问题，有些子问题被**反复计算多次**
- 动态规划对每个子问题只解一次，保存在表格中，再次需要时只需 O(1) 查表
- 不同子问题的个数通常只有**多项式量级**（如 O(n²)）

### 2.3 备忘录方法（Memoization）
- 控制结构与直接递归相同，区别在于为每个解过的子问题建立**备忘录**
- 采用**自顶向下**的方式：先查表，如果没有则计算并存入表
- 与自底向上的动态规划本质相同，只是计算顺序不同

---

## 三、动态规划的设计步骤

1. **找出最优解的性质，并刻划其结构特征**（分析最优子结构）
2. **递归地定义最优值**（建立递推关系式 / 动态规划函数）
3. **以自底向上的方式计算出最优值**（填表）
4. **根据计算最优值时得到的信息，构造最优解**（回溯）

## 四、矩阵连乘问题

### 4.1 问题描述
给定 n 个矩阵 {A₁, A₂, ..., Aₙ}，其中 Aᵢ 与 Aᵢ₊₁ 是可乘的（i = 1, 2, ..., n-1）。
矩阵乘法满足结合律，不同的计算次序（加括号方式）会导致不同的计算量。

**目标**：确定计算矩阵连乘积的计算次序，使得**数乘次数最少**。

**示例**：四个矩阵 A(50×10), B(10×40), C(40×30), D(30×5)，五种加括号方式：
- (A((BC)D)) → 16000 次
- (A(B(CD))) → 10500 次
- ((AB)(CD)) → 36000 次
- (((AB)C)D) → 87500 次
- ((A(BC))D) → 34500 次

### 4.2 最优子结构分析
- 将 A[i:j]（即 AᵢAᵢ₊₁...Aⱼ）在 Aₖ 和 Aₖ₊₁ 之间断开（i ≤ k < j）
- 加括号方式：(Aᵢ...Aₖ)(Aₖ₊₁...Aⱼ)
- 计算量 = A[i:k] 的计算量 + A[k+1:j] 的计算量 + 两者相乘的计算量
- **特征**：计算 A[i:j] 的最优次序所包含的子链 A[i:k] 和 A[k+1:j] 的次序也是最优的 ✓ 最优子结构

### 4.3 递推关系式（动态规划函数）

设 m[i][j] = 计算 A[i:j] 所需的最少数乘次数（1 ≤ i ≤ j ≤ n）
设矩阵 Aᵢ 的维数为 pᵢ₋₁ × pᵢ

```
         ⎧ 0                                    i = j
m[i][j] = ⎨
         ⎩ min{ m[i][k] + m[k+1][j] + pᵢ₋₁·pₖ·pⱼ }   i < j
           i≤k<j
```

- k 的位置只有 j - i 种可能
- 原问题的最优值为 **m[1][n]**
- 用 **s[i][j]** 记录最优断开位置 k

### 4.4 算法步骤
1. 初始化：m[i][i] = 0（i = 1, 2, ..., n）
2. 按矩阵链长度 r = 2, 3, ..., n 依次计算
3. 对于每个长度 r，枚举起点 i，终点 j = i + r - 1
4. 枚举断点 k ∈ [i, j-1]，取最小值
5. 记录最优断开位置 s[i][j] = k

### 4.5 C++ 代码

```cpp
#include <iostream>
#include <vector>
#include <climits>
using namespace std;

/**
 * 矩阵连乘问题 - 动态规划求解
 * @param p  矩阵维度数组，p[0..n]，Ai 的维度为 p[i-1] × p[i]
 * @param n  矩阵个数
 * @param m  m[i][j] 存储 A[i..j] 的最少数乘次数
 * @param s  s[i][j] 存储 A[i..j] 的最优断开位置 k
 *
 * 时间复杂度：O(n³)
 * 空间复杂度：O(n²)
 */
void matrixChain(const vector<int>& p, int n,
                 vector<vector<int>>& m, vector<vector<int>>& s) {
    // 初始化：长度为 1 的矩阵链，数乘次数为 0
    for (int i = 1; i <= n; i++) {
        m[i][i] = 0;
    }

    // r 表示矩阵链的长度（从 2 到 n）
    for (int r = 2; r <= n; r++) {
        // i 表示矩阵链的起点
        for (int i = 1; i <= n - r + 1; i++) {
            int j = i + r - 1;  // 矩阵链的终点

            // 初始值：在 i 处断开
            m[i][j] = m[i + 1][j] + p[i - 1] * p[i] * p[j];
            s[i][j] = i;

            // 枚举所有可能的断开位置 k（i ≤ k < j）
            for (int k = i + 1; k < j; k++) {
                // 在 k 处断开的计算量
                int t = m[i][k] + m[k + 1][j] + p[i - 1] * p[k] * p[j];
                if (t < m[i][j]) {
                    m[i][j] = t;    // 更新最小值
                    s[i][j] = k;    // 记录最优断开位置
                }
            }
        }
    }
}

/**
 * 回溯构造最优加括号方式
 * @param i  起点
 * @param j  终点
 * @param s  最优断开位置表
 *
 * 输出示例：Multiply A1,1 and A2,2（表示 A1 × A2）
 */
void traceback(int i, int j, const vector<vector<int>>& s) {
    if (i == j) {
        cout << "A" << i;  // 单独矩阵直接输出
        return;
    }
    cout << "(";
    traceback(i, s[i][j], s);       // 左半部分 A[i..k]
    traceback(s[i][j] + 1, j, s);   // 右半部分 A[k+1..j]
    cout << ")";
}

int main() {
    // 示例：6个矩阵 A1(30×35), A2(35×15), A3(15×5),
    //               A4(5×10), A5(10×20), A6(20×25)
    vector<int> p = {30, 35, 15, 5, 10, 20, 25};
    int n = p.size() - 1;  // 矩阵个数

    // m[1..n][1..n], s[1..n][1..n]（下标从 1 开始）
    vector<vector<int>> m(n + 1, vector<int>(n + 1));
    vector<vector<int>> s(n + 1, vector<int>(n + 1));

    matrixChain(p, n, m, s);

    cout << "最少数乘次数: " << m[1][n] << endl;
    cout << "最优加括号方式: ";
    traceback(1, n, s);
    cout << endl;

    return 0;
}
/* 输出：
最少数乘次数: 15125
最优加括号方式: ((A1(A2A3))((A4A5)A6))
*/
```

### 4.6 备忘录方法（自顶向下）C++ 代码

```cpp
#include <iostream>
#include <vector>
#include <climits>
using namespace std;

/**
 * 矩阵连乘 - 备忘录方法（自顶向下递归 + 查表）
 * @param i  起点
 * @param j  终点
 * @param p  维度数组
 * @param m  备忘录
 * @param s  断开位置表
 * @return   计算 A[i..j] 的最少数乘次数
 */
int lookupChain(int i, int j, const vector<int>& p,
                vector<vector<int>>& m, vector<vector<int>>& s) {
    // 如果已经计算过，直接返回（查备忘录）
    if (m[i][j] > 0) return m[i][j];

    // 基本情况：单个矩阵
    if (i == j) return 0;

    // 初始值：在 i 处断开
    int u = lookupChain(i + 1, j, p, m, s) + p[i - 1] * p[i] * p[j];
    s[i][j] = i;

    // 枚举所有断开位置
    for (int k = i + 1; k < j; k++) {
        int t = lookupChain(i, k, p, m, s)        // 左半部分
              + lookupChain(k + 1, j, p, m, s)    // 右半部分
              + p[i - 1] * p[k] * p[j];           // 合并代价
        if (t < u) {
            u = t;
            s[i][j] = k;
        }
    }
    m[i][j] = u;  // 存入备忘录
    return u;
}
```

### 4.7 复杂度分析
- **穷举法**：P(n) = Ω(4ⁿ / n^(3/2))（Catalan 数增长）
- **动态规划**：O(n³) 时间，O(n²) 空间
- 三重循环：r(链长) × i(起点) × k(断点)，循环体 O(1)

## 五、最长公共子序列（LCS）

### 5.1 基本定义
- **子序列**：给定序列 X = {x₁, x₂, ..., xₘ}，Z = {z₁, z₂, ..., zₖ} 是 X 的子序列，当且仅当存在严格递增下标序列 {i₁, i₂, ..., iₖ} 使得 zⱼ = x_{iⱼ}
- **公共子序列**：Z 既是 X 的子序列又是 Y 的子序列
- **问题**：给定 X 和 Y，找出 X 和 Y 的**最长公共子序列**

例如：X = {A, B, C, B, D, A, B}，Y = {B, D, C, A, B, A}
- LCS 可以是 {B, C, B, A} 或 {B, D, A, B}

### 5.2 最优子结构分析

设 X = {x₁, ..., xₘ}，Y = {y₁, ..., yₙ}，Z = {z₁, ..., zₖ} 是 LCS，则：

1. **若 xₘ = yₙ**：则 zₖ = xₘ = yₙ，且 Zₖ₋₁ 是 Xₘ₋₁ 和 Yₙ₋₁ 的 LCS
2. **若 xₘ ≠ yₙ 且 zₖ ≠ xₘ**：则 Z 是 Xₘ₋₁ 和 Y 的 LCS
3. **若 xₘ ≠ yₙ 且 zₖ ≠ yₙ**：则 Z 是 X 和 Yₙ₋₁ 的 LCS

→ 最长公共子序列包含其前缀的 LCS，具有**最优子结构性质** ✓

### 5.3 递推关系式

设 c[i][j] = X 的前 i 个字符与 Y 的前 j 个字符的 LCS 长度

```
         ⎧ 0                                    i = 0 或 j = 0
c[i][j] = ⎨ c[i-1][j-1] + 1                     xᵢ = yⱼ
         ⎩ max(c[i-1][j], c[i][j-1])             xᵢ ≠ yⱼ
```

**状态搜索方向 S[i][j]**：
- S[i][j] = 1：xᵢ = yⱼ，来自左上角 ↖
- S[i][j] = 2：xᵢ ≠ yⱼ 且 c[i][j-1] ≥ c[i-1][j]，来自左边 ←
- S[i][j] = 3：xᵢ ≠ yⱼ 且 c[i][j-1] < c[i-1][j]，来自上边 ↑

### 5.4 C++ 代码

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

/**
 * 最长公共子序列 - 动态规划
 * @param X  序列 X（下标从 1 开始）
 * @param Y  序列 Y（下标从 1 开始）
 * @param c  c[i][j] 存储 Xi 和 Yj 的 LCS 长度
 * @param s  s[i][j] 存储搜索方向 (1:↖, 2:←, 3:↑)
 *
 * 时间复杂度：O(mn)
 * 空间复杂度：O(mn)
 */
void lcsLength(const string& X, const string& Y,
               vector<vector<int>>& c, vector<vector<int>>& s) {
    int m = X.length() - 1;  // X 的有效长度（下标从 1 开始）
    int n = Y.length() - 1;  // Y 的有效长度

    // 初始化边界：空序列的 LCS 长度为 0
    for (int i = 0; i <= m; i++) c[i][0] = 0;
    for (int j = 0; j <= n; j++) c[0][j] = 0;

    // 自底向上填表
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (X[i] == Y[j]) {
                // 情况 1：字符相等，LCS 长度 +1
                c[i][j] = c[i - 1][j - 1] + 1;
                s[i][j] = 1;  // ↖ 来自左上角
            } else if (c[i - 1][j] >= c[i][j - 1]) {
                // 情况 2：来自上方的 LCS 更长
                c[i][j] = c[i - 1][j];
                s[i][j] = 2;  // ↑ 来自上方
            } else {
                // 情况 3：来自左方的 LCS 更长
                c[i][j] = c[i][j - 1];
                s[i][j] = 3;  // ← 来自左方
            }
        }
    }
}

/**
 * 回溯构造最长公共子序列
 * @param i  当前 X 下标
 * @param j  当前 Y 下标
 * @param X  序列 X
 * @param s  搜索方向表
 *
 * 注意：此函数按从后往前的顺序输出 LCS 字符
 */
void lcs(int i, int j, const string& X, const vector<vector<int>>& s) {
    // 递归终止条件
    if (i == 0 || j == 0) return;

    if (s[i][j] == 1) {
        // 来自左上角：该字符属于 LCS
        lcs(i - 1, j - 1, X, s);
        cout << X[i];
    } else if (s[i][j] == 2) {
        // 来自上方：向上回溯
        lcs(i - 1, j, X, s);
    } else {
        // 来自左方：向左回溯
        lcs(i, j - 1, X, s);
    }
}

int main() {
    // 示例：注意下标从 1 开始，所以前面加一个空格占位
    string X = " ABCBDAB";  // X[1..7] = "ABCBDAB"
    string Y = " BDCABA";   // Y[1..6] = "BDCABA"

    int m = X.length() - 1;
    int n = Y.length() - 1;

    vector<vector<int>> c(m + 1, vector<int>(n + 1, 0));
    vector<vector<int>> s(m + 1, vector<int>(n + 1, 0));

    lcsLength(X, Y, c, s);

    cout << "LCS 长度: " << c[m][n] << endl;
    cout << "LCS: ";
    lcs(m, n, X, s);
    cout << endl;

    return 0;
}
/* 输出：
LCS 长度: 4
LCS: BCBA
（另一种可能的 LCS 是 BDAB）
*/
```

### 5.5 算法改进
- **省去 S 数组**：c[i][j] 的值可以仅通过比较 c[i-1][j-1]、c[i-1][j]、c[i][j-1] 来确定来源
- **空间优化**：如果只需 LCS 长度，只需保留当前行和上一行（2 行），空间 O(min(m, n))
- **LCS 不唯一**：长度唯一，但序列可能不唯一

## 六、0-1 背包问题

### 6.1 问题描述
给定 n 种物品和一背包。物品 i 的重量为 wᵢ，价值为 vᵢ，背包容量为 C。
问：如何选择装入背包的物品（每种物品要么全装要么不装），使得总价值最大？

**数学形式**：
```
max  Σ vᵢ·xᵢ
s.t. Σ wᵢ·xᵢ ≤ C
     xᵢ ∈ {0, 1},  i = 1, 2, ..., n
```

### 6.2 最优子结构分析

设最优解序列为 {x₁, x₂, ..., xₙ}：
- **如果 x₁ = 1**（选第 1 个物品），则 {x₂, ..., xₙ} 是容量为 C-w₁ 的子问题的最优解
- **如果 x₁ = 0**（不选第 1 个物品），则 {x₂, ..., xₙ} 是容量为 C 的子问题的最优解

→ 问题的最优解包含其子问题的最优解 ✓ **最优子结构性质**

### 6.3 递推关系式

设 **m(i, j)** = 背包容量为 j，可选物品为 i, i+1, ..., n 时的最优价值

```
              ⎧ max{ m(i+1, j), m(i+1, j-wᵢ) + vᵢ }    j ≥ wᵢ
              ⎪         不选第i个      选第i个
m(i, j) =     ⎨
              ⎩ m(i+1, j)                              0 ≤ j < wᵢ
                       第i个装不下

边界条件：
              ⎧ vₙ     j ≥ wₙ
m(n, j) =     ⎨
              ⎩ 0      0 ≤ j < wₙ
```

### 6.4 C++ 代码（基础版本）

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

/**
 * 0-1 背包问题 - 动态规划
 * @param v  价值数组 v[1..n]
 * @param w  重量数组 w[1..n]
 * @param C  背包容量
 * @param n  物品数量
 * @param m  m[i][j] 表示容量为 j，可选物品 i..n 时的最优价值
 *
 * 时间复杂度：O(nC)
 * 空间复杂度：O(nC)
 */
void knapsack(const vector<int>& v, const vector<int>& w,
              int C, int n, vector<vector<int>>& m) {
    // ========== 处理最后一个物品（边界） ==========
    int jMax = min(w[n] - 1, C);
    // 容量不足以装下第 n 个物品
    for (int j = 0; j <= jMax; j++) {
        m[n][j] = 0;
    }
    // 容量足够装下第 n 个物品
    for (int j = w[n]; j <= C; j++) {
        m[n][j] = v[n];
    }

    // ========== 从后往前递推（i = n-1 到 2） ==========
    for (int i = n - 1; i >= 2; i--) {
        jMax = min(w[i] - 1, C);
        // 容量不足以装下第 i 个物品 → 只能不选
        for (int j = 0; j <= jMax; j++) {
            m[i][j] = m[i + 1][j];
        }
        // 容量足够 → 比较"选"与"不选"
        for (int j = w[i]; j <= C; j++) {
            m[i][j] = max(m[i + 1][j],                // 不选第 i 个
                          m[i + 1][j - w[i]] + v[i]); // 选第 i 个
        }
    }

    // ========== 处理第 1 个物品 ==========
    if (C >= w[1]) {
        m[1][C] = max(m[2][C], m[2][C - w[1]] + v[1]);
    } else {
        m[1][C] = m[2][C];
    }
}

/**
 * 回溯构造最优解（确定每个物品是否被选中）
 * @param m  最优价值表
 * @param w  重量数组
 * @param C  背包容量
 * @param n  物品数量
 * @param x  输出：x[i] = 1 表示选中物品 i
 */
void traceback(const vector<vector<int>>& m, const vector<int>& w,
               int C, int n, vector<int>& x) {
    for (int i = 1; i < n; i++) {
        if (m[i][C] == m[i + 1][C]) {
            // 价值相等 → 第 i 个物品没有被选中
            x[i] = 0;
        } else {
            // 价值不等 → 第 i 个物品被选中
            x[i] = 1;
            C -= w[i];  // 减去该物品的重量
        }
    }
    // 最后一个物品：看剩余容量是否足够
    x[n] = (m[n][C] > 0) ? 1 : 0;
}

int main() {
    // 示例：4 个物品，容量 5
    // 重量: w = {0, 2, 1, 3, 2}  (w[1]=2, w[2]=1, w[3]=3, w[4]=2)
    // 价值: v = {0, 12, 10, 20, 15}
    int n = 4;
    int C = 5;
    vector<int> w = {0, 2, 1, 3, 2};   // 下标从 1 开始
    vector<int> v = {0, 12, 10, 20, 15};

    vector<vector<int>> m(n + 1, vector<int>(C + 1, 0));
    vector<int> x(n + 1, 0);

    knapsack(v, w, C, n, m);

    cout << "最大价值: " << m[1][C] << endl;

    traceback(m, w, C, n, x);
    cout << "选中物品: ";
    for (int i = 1; i <= n; i++) {
        if (x[i]) cout << i << " ";
    }
    cout << endl;

    return 0;
}
/* 输出：
最大价值: 37
选中物品: 1 2 4
*/
```

### 6.5 跳跃点优化（Jump Point Optimization）

**观察**：函数 m(i, j) 是关于 j 的**阶梯状单调不减函数**。可以用"跳跃点"来表示。

**方法**：
- p[i] 存储 m(i, j) 的全部跳跃点 (j, m(i, j))，按 j 升序排列
- 初始：p[n+1] = {(0, 0)}
- q[i+1] = p[i+1] ⊕ (wᵢ, vᵢ) = {(j + wᵢ, m(i, j) + vᵢ)}
- p[i] = p[i+1] ∪ q[i+1]，并**去除受控点**（若 (a,b) 和 (c,d) 满足 c≥a 且 d≤b，则 (c,d) 受控于 (a,b)，应去除）

### 6.6 跳跃点优化 C++ 代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// 跳跃点结构：first = 重量, second = 价值
typedef pair<int, int> JumpPoint;

/**
 * 0-1背包问题 - 跳跃点优化版本
 * 时间复杂度：O(min{nC, 2^n})，实际通常优于 O(nC)
 */
int knapsackJumpPoint(const vector<int>& w, const vector<int>& v,
                      int C, int n, vector<int>& x) {
    // p 存储当前阶段的跳跃点
    vector<JumpPoint> p;
    p.push_back({0, 0});  // 初始跳跃点

    // 从最后一个物品向前处理（与基础版本方向一致）
    for (int i = n; i >= 1; i--) {
        // q = p ⊕ (w[i], v[i])：每个跳跃点加上当前物品
        vector<JumpPoint> q;
        for (auto& jp : p) {
            int newW = jp.first + w[i];
            int newV = jp.second + v[i];
            if (newW <= C) {  // 只保留容量范围内
                q.push_back({newW, newV});
            }
        }

        // 合并 p 和 q（类似归并排序的合并）
        vector<JumpPoint> merged;
        int a = 0, b = 0;
        while (a < p.size() && b < q.size()) {
            if (p[a].first < q[b].first)
                merged.push_back(p[a++]);
            else if (p[a].first > q[b].first)
                merged.push_back(q[b++]);
            else {
                // 重量相同，取价值大的
                merged.push_back({p[a].first, max(p[a].second, q[b].second)});
                a++; b++;
            }
        }
        while (a < p.size()) merged.push_back(p[a++]);
        while (b < q.size()) merged.push_back(q[b++]);

        // 去除受控点：若后面的重量≥前面但价值≤前面，则去除
        p.clear();
        int maxV = -1;
        for (auto& jp : merged) {
            if (jp.second > maxV) {  // 只有在价值更大时才保留
                maxV = jp.second;
                p.push_back(jp);
            }
            // 若 jp.second <= maxV，则是受控点，丢弃
        }
    }

    // p 的最后一个元素即为最优解
    return p.back().second;
}

int main() {
    // 示例：5 个物品，容量 10
    vector<int> w = {0, 2, 2, 6, 5, 4};  // 下标从 1
    vector<int> v = {0, 6, 3, 5, 4, 6};
    int n = 5, C = 10;
    vector<int> x(n + 1, 0);

    int maxVal = knapsackJumpPoint(w, v, C, n, x);
    cout << "最大价值（跳跃点优化）: " << maxVal << endl;

    return 0;
}
/* 输出：
最大价值（跳跃点优化）: 15
*/
```

### 6.7 复杂度分析
- **基础 DP**：O(nC) 时间，O(nC) 空间
- **跳跃点优化**：O(min{nC, 2ⁿ})，在实际中通常更优
- 背包问题是**伪多项式时间**算法（依赖于容量 C 的数值大小）

## 七、流水作业调度问题

### 7.1 问题描述
n 个作业 {1, 2, ..., n} 要在 2 台机器 M₁ 和 M₂ 上加工。
- 每个作业**必须先 M₁ 后 M₂**
- 作业 i 在 M₁ 上耗时 aᵢ，在 M₂ 上耗时 bᵢ
- **目标**：确定最优加工顺序，使总加工时间（从第一个作业开始到最后一个完成）**最短**

### 7.2 最优子结构
- 设 π 是最优调度，加工时间为 a_π(1) + T'，其中 T' 是在 M₂ 等待时间为 b_π(1) 时安排剩余作业的时间
- 记 S = N - {π(1)}，则 T' = T(S, b_π(1))
- 通过反证法可证流水作业调度问题具有最优子结构性质 ✓

### 7.3 递推关系式

设 T(S, t) 表示在 M₂ 等待时间为 t 时，完成作业集 S 的最短时间：

```
T(N, 0) = min { aᵢ + T(N - {i}, bᵢ) }               (1)
          1≤i≤n

T(S, t) = min { aᵢ + T(S - {i}, bᵢ + max{t - aᵢ, 0}) }   (2)
          i∈S
```

含义：
- aᵢ：当前作业在 M₁ 上的加工时间
- bᵢ + max{t - aᵢ, 0}：新的 M₂ 等待时间
  - t - aᵢ > 0：M₂ 还需等 t - aᵢ 时间
  - t - aᵢ ≤ 0：M₂ 直接在 M₁ 完成作业后就能开始

### 7.4 Johnson 不等式与 Johnson 法则

**Johnson 不等式**：作业 i 和 j 满足 **min{bᵢ, aⱼ} ≥ min{bⱼ, aᵢ}** 时，i 应排在 j 之前。

**Johnson 法则（最优调度算法）**：
1. 令 N₁ = { i | aᵢ < bᵢ }（M₁ 更快）→ 按 aᵢ **非减序**排列
2. 令 N₂ = { i | aᵢ ≥ bᵢ }（M₂ 更快或相等）→ 按 bᵢ **非增序**排列
3. 最优调度 = N₁ 中作业（顺序） + N₂ 中作业（顺序）

**直观理解**：
- aᵢ < bᵢ 的作业（M₁ 短 M₂ 长）：先做，让 M₂ 尽早开始
- aᵢ ≥ bᵢ 的作业（M₁ 长 M₂ 短）：后做，让 M₂ 不会积压

### 7.5 C++ 代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

/**
 * 流水作业调度 - Johnson 法则
 * @param a  M1 上的加工时间数组
 * @param b  M2 上的加工时间数组
 * @param n  作业数量
 * @param c  输出：最优调度顺序（作业编号）
 * @return   最短总加工时间
 *
 * 时间复杂度：O(n log n)（主要是排序）
 * 空间复杂度：O(n)
 */
struct Element {
    int key;    // 排序关键字（取 min(a[i], b[i])）
    int index;  // 作业编号
    bool job;   // true=属于N1(a<b), false=属于N2(a>=b)
};

int flowShop(const vector<int>& a, const vector<int>& b,
             int n, vector<int>& c) {
    // 步骤1：为每个作业创建 Element
    vector<Element> d(n);
    for (int i = 0; i < n; i++) {
        // 关键字：取 a[i] 和 b[i] 中的较小值
        int key = (a[i] >= b[i]) ? b[i] : a[i];
        // 属于 N1（a < b）还是 N2（a >= b）
        bool job = (a[i] < b[i]);
        d[i] = {key, i, job};
    }

    // 步骤2：按关键字升序排序
    sort(d.begin(), d.end(), [](const Element& e1, const Element& e2) {
        return e1.key < e2.key;
    });

    // 步骤3：构造最优调度
    // N1 的作业从前往后放，N2 的作业从后往前放
    int j = 0, k = n - 1;
    for (int i = 0; i < n; i++) {
        if (d[i].job) {
            c[j++] = d[i].index;   // N1：非减序 → 放前面
        } else {
            c[k--] = d[i].index;   // N2：非增序 → 放后面
        }
    }

    // 步骤4：计算最优总加工时间
    // 模拟流水线加工过程
    int j_time = a[c[0]];             // M1 上累积时间
    int k_time = j_time + b[c[0]];    // M2 上累积时间（需等 M1 完成第一个作业）

    for (int i = 1; i < n; i++) {
        j_time += a[c[i]];  // M1 上继续加工
        // M2 开始时间 = max(M1完成时间, M2上一作业完成时间)
        k_time = (j_time < k_time)
                 ? k_time + b[c[i]]     // M2 在等 M1
                 : j_time + b[c[i]];    // M1 在等 M2
    }

    return k_time;  // 返回总加工时间
}

int main() {
    // 示例数据（与课件一致）
    vector<int> a = {2, 4, 3, 6, 1};  // M1 加工时间
    vector<int> b = {5, 2, 3, 1, 7};  // M2 加工时间
    int n = a.size();
    vector<int> c(n);  // 存储最优调度顺序

    int minTime = flowShop(a, b, n, c);

    cout << "最短总加工时间: " << minTime << endl;
    cout << "最优调度顺序（作业编号从0开始）: ";
    for (int i = 0; i < n; i++) {
        cout << c[i] << " ";
    }
    cout << endl;

    // 按顺序输出各作业的加工时间
    cout << "\n详细调度方案:" << endl;
    cout << "作业\tM1时间\tM2时间" << endl;
    for (int i = 0; i < n; i++) {
        cout << "J" << c[i] << "\t" << a[c[i]] << "\t" << b[c[i]] << endl;
    }

    return 0;
}
/* 输出：
最短总加工时间: 19
最优调度顺序（作业编号从0开始）: 4 0 2 1 3

详细调度方案:
作业    M1时间 M2时间
J4      1       7
J0      2       5
J2      3       3
J1      4       2
J3      6       1
*/
```

### 7.6 复杂度分析
- **穷举法**：O(n!)（所有排列）
- **动态规划**：O(2ⁿ)（子集枚举）
- **Johnson 法则**：O(n log n)（排序最优），空间 O(n)

## 八、货郎担问题（TSP）

### 8.1 问题描述
n 个城市用 1 ~ n 编号，在有向赋权图 G = <V, E> 中寻找一条路径最短的**哈密尔顿回路**（每个城市经过一次且仅一次，最后回到起点）。

用邻接矩阵 C 表示各城市间距离：若 (i,j) ∈ E，则 Cᵢⱼ > 0，否则 Cᵢⱼ = ∞。

### 8.2 递推关系式

设 **d(i, V)** 表示从顶点 i 出发，经过 V 中各顶点一次，最终回到 i 的最短路径长度。

```
d(i, V - {i}) = d(i, V) = min { Cᵢₖ + d(k, V - {k}) }
                      k∈V

边界：d(k, ∅) = Cₖᵢ（直接回到起点 i）
```

### 8.3 示例计算

4 个城市的费用矩阵：
```
    ∞  3  6  7
    5  ∞  2  3
    6  4  ∞  2
    3  7  5  ∞
```

计算 d(1, {2,3,4})：
- d(2, {3,4}) = min{2+5, 3+11} = 7，路径：2→3→4→1
- d(3, {2,4}) = min{4+6, 2+12} = 10，路径：3→2→4→1
- d(4, {2,3}) = min{7+8, 5+9} = 14，路径：4→2→3→1
- d(1, {2,3,4}) = min{3+7, 6+10, 7+14} = 10

**最短路径长度 = 10**

### 8.4 C++ 代码

```cpp
#include <iostream>
#include <vector>
#include <climits>
using namespace std;

/**
 * 货郎担问题 (TSP) - 动态规划（状态压缩）
 * @param dist  距离矩阵 dist[i][j]（0-based）
 * @param n     城市数量
 * @return      最短哈密尔顿回路长度
 *
 * 状态 dp[mask][i]：
 *   mask: 已访问城市的位掩码（bit j = 1 表示城市 j 已访问）
 *   i:    当前所在城市
 *   值:   从城市 0 出发，经过 mask 中所有城市，最终到达 i 的最短路径
 *
 * 时间复杂度：O(n²·2ⁿ)
 * 空间复杂度：O(n·2ⁿ)
 */
int tsp(const vector<vector<int>>& dist, int n) {
    int N = 1 << n;  // 状态总数 2ⁿ

    // dp[mask][i]：初始化所有值为无穷大
    vector<vector<int>> dp(N, vector<int>(n, INT_MAX / 2));

    // 初始状态：从城市 0 出发，只访问了城市 0
    dp[1][0] = 0;  // mask=1 表示只访问了城市 0

    // 枚举所有状态
    for (int mask = 1; mask < N; mask++) {
        // 枚举当前所在城市 i（必须在 mask 中）
        for (int i = 0; i < n; i++) {
            if (!(mask & (1 << i))) continue;  // i 不在 mask 中
            if (dp[mask][i] == INT_MAX / 2) continue;

            // 枚举下一个要访问的城市 j（不能在 mask 中）
            for (int j = 0; j < n; j++) {
                if (mask & (1 << j)) continue;  // j 已经访问过
                if (dist[i][j] == INT_MAX / 2) continue;  // 不可达

                int nextMask = mask | (1 << j);  // 将 j 加入已访问集合
                dp[nextMask][j] = min(dp[nextMask][j],
                                      dp[mask][i] + dist[i][j]);
            }
        }
    }

    // 答案：从所有城市回到起点0的最短路径
    int ans = INT_MAX / 2;
    int fullMask = N - 1;  // 全部城市都已访问
    for (int i = 1; i < n; i++) {
        if (dist[i][0] < INT_MAX / 2) {
            ans = min(ans, dp[fullMask][i] + dist[i][0]);
        }
    }

    return ans;
}

int main() {
    // 4 个城市示例
    const int INF = INT_MAX / 2;
    vector<vector<int>> dist = {
        {INF, 3,   6,   7},
        {5,   INF, 2,   3},
        {6,   4,   INF, 2},
        {3,   7,   5,   INF}
    };
    int n = 4;

    int result = tsp(dist, n);
    cout << "最短哈密尔顿回路长度: " << result << endl;

    return 0;
}
/* 输出：
最短哈密尔顿回路长度: 10
对应路径：1 → 2 → 3 → 4 → 1
*/
```

### 8.5 复杂度分析
- **穷举法**：O(n!) 
- **动态规划（状态压缩）**：O(n² · 2ⁿ)，比穷举法好很多但不是多项式

### 习题 2
**给定 5 种物品和一背包。重量分别是 {2, 2, 6, 5, 4}，价值分别为 {6, 3, 5, 4, 6}，背包的容量为 10。问应如何选择装入背包中的物品，使得总价值最大？**

**解答**：使用跳跃点法（详见 6.5 节实例），最终：

- 或：物品 1（2,6）+ 物品 5（4,6）+ 物品 4（5,4）= 重量 11 > 10，不可行
- **最优解为选取物品 1, 2, 5，总价值 15**

## 总结：动态规划解题模板

```
1. 分析最优子结构 → 证明问题可用 DP
2. 建立递推关系式 → 这是核心，也是难点
3. 自底向上填表计算 → 注意填表顺序
4. 回溯构造最优解   → 根据记录的信息反向追踪
```

**关键特征判断**：
- 问题能分解为重叠子问题
- 存在最优子结构
- 可以用递推关系描述

**复杂度特点**：
- 时间 = 子问题个数 × 每个子问题的决策数
- 空间 = 存储所有子问题解所需的表格大小
