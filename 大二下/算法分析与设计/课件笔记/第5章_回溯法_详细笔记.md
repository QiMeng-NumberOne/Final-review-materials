## 一、回溯法概述

### 1.1 什么是回溯法

> 回溯法有"**通用的解题法**"之称，是一个既带有**系统性**又带有**跳跃性**的搜索算法。

**基本思想**（课件原文）：

> 从问题的某一种状态（初始状态）出发，搜索从这种状态出发所能达到的所有"状态"，当一条路走到"尽头"的时候（不能再前进），再**后退一步或若干步**，从另一种可能"状态"出发，继续搜索，直到所有的"路径"（状态）都试探过。这种不断"**前进**"、不断"**回溯**"寻找解的方法，就称作"回溯法"。

**一句话**：走不通，就掉头。

### 1.2 本质

回溯法是一种**组织得井井有条的、能避免不必要搜索的穷举式搜索法**。适用于解一些**组合数相当大**的问题。

### 1.3 回溯法与之前算法的区别

| | 动态规划 | 贪心算法 | 回溯法 |
|---|---|---|---|
| **搜索方式** | 自底向上填表 | 自顶向下贪心选择 | **深度优先试探+回溯** |
| **是否穷举** | 计算所有子问题 | 只选一条路 | 系统地搜索，但**剪枝**跳过无用分支 |
| **有"后悔"吗** | 无（填表确定） | 无（永不回头） | **有！试错了就退回** |
| **适用问题** | 最优子结构+重叠子问题 | 最优子结构+贪心选择 | 组合数大、需要找所有解或最优解 |

## 二、解空间与状态空间树

### 2.1 解向量

回溯法希望问题的解能表示成一个 **n 元组** (x₁, x₂, …, xₙ)。

### 2.2 约束条件

| 类型 | 含义 | 例子（0-1背包） |
|------|------|----------------|
| **显约束** | 对分量 xᵢ 的**取值限定** | xᵢ ∈ {0, 1} |
| **隐约束** | 分量之间的**关系约束** | Σ wᵢxᵢ ≤ C |

### 2.3 解空间（Solution Space）

解向量满足显式约束条件的**所有多元组**构成解空间。

> 同一个问题可以有多种解空间表示，有些更简单、状态空间更小。

**例**：n=3 的 0-1 背包，解空间是包含 2³=8 个叶子的完全二叉树。

### 2.4 状态空间树的结点类型

| 术语 | 含义 |
|------|------|
| **问题状态** | 树中每个结点确定一个"问题状态" |
| **状态空间** | 根到所有结点的路径集合 |
| **扩展结点** | 一个**正在产生儿子**的结点 |
| **活结点** | 自身已生成但**儿子还没全生成**的结点 |
| **死结点** | **所有儿子都已生成**的结点 |
| **回答结点** | 满足所有约束条件的解状态结点 |

### 2.5 深度优先 vs 宽度优先

```
深度优先生成法：一旦产生了一个儿子S，立刻把S当做新的扩展结点。
              搜索完S的子树后，才回到原来的扩展结点继续生成下一个儿子。
              → 回溯法用的是这个！

宽度优先生成法：在一个扩展结点变成死结点之前，它一直是扩展结点。
              → 分支限界法（第六章）用的是这个！
```

### 2.6 回溯法的空间优势

> 在搜索期间的任何时刻，**仅保留从开始节点到当前节点的路径**。空间需求为 O(最长路径长度)。解空间大小通常是指数/阶乘级别的，如果全部存储根本存不下。

## 三、剪枝函数

回溯法不是盲目穷举——通过**剪枝函数**跳过不可能产生解的分支。

### 两类剪枝函数

| 类型 | 作用 | 例子 |
|------|------|------|
| **约束函数 Constraint** | 剪去**不满足约束**的子树 | 0-1背包：当前重量 > 容量 → 剪 |
| **限界函数 Bound** | 剪去**得不到最优解**的子树 | 0-1背包：当前价值+剩余最大可能 ≤ 已有最优 → 剪 |

> **具有限界函数的深度优先生成法 = 回溯法**

## 四、两种解空间树与算法框架

### 4.1 子集树（Subset Tree）

**适用场景**：从 n 个元素的集合中找出满足某种性质的**子集**。

**特征**：
- 每个结点分两支：选 or 不选
- 叶子数 = **2ⁿ**
- 结点总数 = 2ⁿ⁺¹ - 1
- 遍历需要 **Ω(2ⁿ)** 时间

**典型问题**：0-1 背包、装载问题、子集和问题

```
子集树形态（n=3）：
              root
            /      \
         选1        不选1
        /   \       /   \
      选2  不选2  选2  不选2
      / \   / \   / \   / \
     3 否 3 否  3 否 3 否
```

**算法框架**：

```cpp
void backtrack(int t) {              // t: 当前层数（第几个元素）
    if (t > n) {                     // 到达叶子
        output(x);                   // 输出/更新解
        return;
    }
    for (int i = 0; i <= 1; i++) {   // 两个分支：0（不选）或 1（选）
        x[t] = i;
        if (legal(t))                // 满足约束 → 深入
            backtrack(t + 1);
    }
}
```

### 4.2 排列树（Permutation Tree）

**适用场景**：确定 n 个元素满足某种性质的**排列**。

**特征**：
- 第 i 层有 n-i+1 个分支
- 叶子数 = **n!**
- 遍历需要 **Ω(n!)** 时间

**典型问题**：旅行售货员 TSP、批处理作业调度、n 皇后

```
排列树形态（n=3）：
                root
           /     |     \
         1       2       3          ← 第1个位置选谁
        / \     / \     / \
       2   3   1   3   1   2        ← 第2个位置
       |   |   |   |   |   |
       3   2   3   1   2   1        ← 第3个位置
```

**算法框架**：

```cpp
void backtrack(int t) {              // t: 当前层数
    if (t > n) {                     // 到达叶子
        output(x);                   // 输出排列
        return;
    }
    for (int i = t; i <= n; i++) {   // 从剩下的元素中选
        swap(x[t], x[i]);            // 把第 i 个元素放到位置 t
        if (legal(t))                // 满足约束 → 深入
            backtrack(t + 1);
        swap(x[t], x[i]);            // 恢复！关键步骤
    }
}
```

**注意排列树的关键**：`swap` 之后必须 `swap` 回来恢复原状（回溯的精髓）。

## 五、递归回溯与迭代回溯

### 5.1 递归回溯（常用）

```cpp
/**
 * 递归回溯通用框架
 * @param t  当前搜索深度（层数）
 *
 * f(n,t): 当前扩展结点未搜索子树的起始编号
 * g(n,t): 当前扩展结点未搜索子树的终止编号
 * h(i):   x[t] 的第 i 个可选值
 */
void Backtrack(int t) {
    if (t > n) {
        Output(x);                   // 到达叶子，输出解
    } else {
        for (int i = f(n, t); i <= g(n, t); i++) {
            x[t] = h(i);             // 尝试第 i 个可选值
            if (Constraint(t) && Bound(t))  // 剪枝判断
                Backtrack(t + 1);    // 满足条件，进入下一层
        }
    }
}
// 调用：Backtrack(1)
```

**if 语句含义**：
- `Constraint(t)` 返回 true → x[1:t] 满足问题的**约束条件**
- `Bound(t)` 返回 true → x[1:t] **未使目标函数越界**，还需继续搜索

### 5.2 迭代回溯（非递归）

```cpp
/**
 * 迭代回溯 - 非递归版本
 * 用 while 循环模拟递归的深入与回溯
 */
void iterativeBacktrack() {
    int t = 1;                       // 从第 1 层开始
    while (t > 0) {
        if (f(n, t) <= g(n, t)) {    // 还有未搜索的子树
            for (int i = f(n, t); i <= g(n, t); i++) {
                x[t] = h(i);
                if (Constraint(t) && Bound(t)) {
                    if (Solution(t)) // 是否已是完整解
                        Output(x);   // 输出可行解
                    else
                        t++;         // 纵深前进！
                }
            }
        } else {
            t--;                     // 无路可走，回溯！
        }
    }
}
```

## 六、0-1背包问题（回溯法）

### 6.1 解空间结构

- **解向量**：x = (x₁, x₂, …, xₙ)，xᵢ ∈ {0, 1}
- **解空间树**：**子集树**，共 2ⁿ 个叶子

### 6.2 约束条件

```
显约束：xᵢ ∈ {0, 1}
隐约束（可行性）：Σ wᵢ·xᵢ ≤ C
```

### 6.3 剪枝策略

**左子树（选当前物品）**：用**约束函数**剪枝
```
if (cw + w[i] <= C)  进入左子树  // 装得下才进去
```

**右子树（不选当前物品）**：用**限界函数**剪枝
```
if (bound(i+1) > bestp)  进入右子树  // 上界比当前最优大才有希望
```

### 6.4 上界函数 bound()

**思想**：将剩余物品按**单位重量价值降序**排列，依次装入，装不下时取一部分装满。这样得到的价值是**理论上能得到的最大值**（上界）。

```cpp
/**
 * 计算当前结点的上界
 * 贪心式地装入剩余物品（允许分割）来估计最大可能价值
 */
double bound(int i) {
    double cleft = C - cw;           // 剩余容量
    double b = cp;                    // 上界 = 当前已有价值

    // 按单位价值降序，尽可能装入完整物品
    while (i <= n && w[i] <= cleft) {
        cleft -= w[i];
        b += v[i];
        i++;
    }
    // 装不下完整物品时，取一部分装满
    if (i <= n)
        b += v[i] / w[i] * cleft;    // 单位价值 × 剩余容量

    return b;
}
```

**实例**：n=4, C=7, v={9,10,7,4}, w={3,5,2,1}

```
单位价值: 3, 2, 2.8(=7/2.5...), 4

排序后装入：物品4(4), 物品3(7), 物品1(9/3→部分)
上界 = 4 + 7 + 9/3 × 1 = 4+7+3 = 14（或课件上算法给出的22，取决于排序后具体计算）
```

### 6.5 完整搜索过程示例

n=3, C=30, w={16, 15, 15}, v={45, 25, 25}

```
                A(cw=0, cv=0)
              /            \
        B(cw=16,cv=45)    C(cw=0,cv=0)
         /      \          /      \
    D(×)   E(cw=16,cv=45) F(15,25) G(0,0)
   超重       /    \        /   \     /  \
          J(×) K(叶子)  L(0,50) M   N    O
          超重  cv=45   ✓最优  25<50 25  0

搜索过程：
A→B→D(超重,回溯)→E→J(超重,回溯)→K(叶子,cv=45,best=45)
→回到B→回到A→C→F→L(叶子,cv=50>45,更新best=50)
→M(25<50)→回到F→G→N(25)→O(0)
最终：bestV=50, bestX=(0,1,1)
```

### 6.6 C++ 代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

/**
 * 0-1背包问题 - 回溯法（子集树 + 剪枝）
 *
 * 时间复杂度：O(n·2ⁿ)（最坏情况）
 * 空间复杂度：O(n)（仅保留当前路径）
 */
class KnapsackBacktrack {
private:
    int n;              // 物品数量
    double C;           // 背包容量
    vector<double> w, v; // 重量、价值
    double cw, cp;      // 当前重量、当前价值
    double bestp;       // 当前最优价值
    vector<int> x;      // 当前解
    vector<int> bestx;  // 当前最优解

public:
    KnapsackBacktrack(int n_, double C_, vector<double>& w_, vector<double>& v_)
        : n(n_), C(C_), w(w_), v(v_), cw(0), cp(0), bestp(0) {
        x.resize(n + 1);
        bestx.resize(n + 1);
    }

    /**
     * 计算上界：贪心式装入剩余物品
     * @param i  当前考虑的物品编号
     * @return   当前结点可能达到的最大价值上界
     */
    double bound(int i) {
        double cleft = C - cw;       // 剩余容量
        double b = cp;                // 上界初始值 = 当前价值

        // 按序装入剩余物品（假设已按单位价值降序排好）
        while (i <= n && w[i] <= cleft) {
            cleft -= w[i];
            b += v[i];
            i++;
        }
        // 装一部分装满背包
        if (i <= n)
            b += v[i] / w[i] * cleft;

        return b;
    }

    /**
     * 递归回溯搜索
     * @param i  当前搜索层数（第 i 个物品）
     */
    void backtrack(int i) {
        if (i > n) {                 // 到达叶子结点
            if (cp > bestp) {        // 更新最优解
                bestp = cp;
                for (int j = 1; j <= n; j++)
                    bestx[j] = x[j];
            }
            return;
        }

        // ===== 搜索左子树（选物品 i） =====
        if (cw + w[i] <= C) {        // 约束函数：装得下吗？
            x[i] = 1;
            cw += w[i];
            cp += v[i];
            backtrack(i + 1);        // 深入下一层
            cw -= w[i];              // 回溯：恢复现场
            cp -= v[i];
        }

        // ===== 搜索右子树（不选物品 i） =====
        if (bound(i + 1) > bestp) {  // 限界函数：有希望超过当前最优吗？
            x[i] = 0;
            backtrack(i + 1);        // 深入下一层
        }
    }

    void solve() {
        backtrack(1);
        cout << "最大价值: " << bestp << endl;
        cout << "选中物品: ";
        for (int i = 1; i <= n; i++)
            if (bestx[i]) cout << i << " ";
        cout << endl;
    }
};

int main() {
    // 示例：n=3, C=30, w={16,15,15}, v={45,25,25}
    int n = 3;
    double C = 30;
    // 下标从 1 开始
    vector<double> w = {0, 16, 15, 15};
    vector<double> v = {0, 45, 25, 25};

    KnapsackBacktrack solver(n, C, w, v);
    solver.solve();

    return 0;
}
/* 输出：
最大价值: 50
选中物品: 2 3
*/
```

## 七、旅行售货员问题（TSP）

### 7.1 问题描述

给定 n 个城市和城市间的距离，找一条从城市 1 出发，经过每个城市**恰好一次**，最后回到城市 1 的**最短路径**。

### 7.2 解空间

- **解空间树**：**排列树**
- 解向量：(1, v₂, v₃, …, vₙ, 1)，v₂~vₙ 是 {2,3,…,n} 的一个排列
- 叶子数 = **(n-1)!**

### 7.3 搜索过程示例

```
4 城市，邻接矩阵：
    1   2   3   4
1   ∞  30   6   4
2  30   ∞   5  10
3   6   5   ∞  20
4   4  10  20   ∞

A（起点=1，当前费用=0）
├── B（选2，费用=30）
│   ├── C（选3，费用=30+5=35）
│   │   ├── F（选4，费用=35+20=55）
│   │   │   └── L（回1，费用=55+4=59）→ best=59
│   │   └── G（选4后回1=66）→ 剪
│   ├── D（选4，费用=30+10=40）
│   │   └── H→N：1,3,2,4,1 = 25 → 更新 best=25！
│   └── E
├── C'（选3，费用=6）
│   └── ...
│       1,3,2,4,1 → 费用 < 25（更新）
└── ...
搜索到 1,3,2,4,1 费用=25 为最优
```

### 7.4 剪枝

用当前费用 + 剩余最短边的估计来剪枝：

```
if (当前费用 + 剩余路径下界 >= bestc)
    剪枝！（不可能比当前最优更好了）
```

### 7.5 C++ 代码

```cpp
#include <iostream>
#include <vector>
#include <climits>
#include <algorithm>
using namespace std;

const int INF = INT_MAX / 2;

/**
 * TSP - 回溯法（排列树 + 剪枝）
 *
 * 时间复杂度：O(n!)（最坏）
 */
class TSPBacktrack {
private:
    int n;                          // 城市数
    vector<vector<int>> dist;       // 距离矩阵
    vector<int> x;                  // 当前路径
    vector<int> bestx;              // 最优路径
    int cc;                         // 当前费用
    int bestc;                      // 最优费用
    int start;                      // 起点

public:
    TSPBacktrack(vector<vector<int>>& d, int s = 0)
        : n(d.size()), dist(d), start(s), cc(0), bestc(INF) {
        x.resize(n);
        bestx.resize(n + 1);
        for (int i = 0; i < n; i++) x[i] = i;
        // 把起点换到第一个位置
        swap(x[0], x[start]);
    }

    /**
     * 递归回溯
     * @param t  当前层（第 t 个要访问的城市）
     */
    void backtrack(int t) {
        if (t == n - 1) {            // 还剩最后一个城市
            int last = x[n - 1];
            // 最后一个城市 → 回到起点，构成完整回路
            if (dist[x[n - 2]][last] != INF &&
                dist[last][x[0]] != INF) {
                int total = cc + dist[x[n - 2]][last] + dist[last][x[0]];
                if (total < bestc) {
                    bestc = total;
                    for (int i = 0; i < n; i++)
                        bestx[i] = x[i];
                    bestx[n] = x[0]; // 回到起点
                }
            }
            return;
        }

        // 枚举剩余城市（排列树的 swap 模式）
        for (int i = t; i < n; i++) {
            // 从 x[t-1] 到 x[i] 是否可达
            if (dist[x[t - 1]][x[i]] != INF) {
                int newCost = cc + dist[x[t - 1]][x[i]];

                // 剪枝：当前费用 + 下界 如果已经 ≥ bestc，跳过
                if (newCost < bestc) {
                    swap(x[t], x[i]);        // 把 x[i] 放到位置 t
                    cc = newCost;
                    backtrack(t + 1);        // 深入
                    cc -= dist[x[t - 1]][x[t]]; // 回溯
                    swap(x[t], x[i]);        // 恢复
                }
            }
        }
    }

    void solve() {
        backtrack(1);  // 从第 1 个位置开始选（第 0 个是起点）
        cout << "最短路径长度: " << bestc << endl;
        cout << "路径: ";
        for (int i = 0; i <= n; i++)
            cout << bestx[i] + 1 << " ";  // 输出 1-based
        cout << endl;
    }
};

int main() {
```

## 八、装载问题

### 8.1 问题描述

n 个集装箱，两艘船容量 c₁, c₂。Σ wᵢ ≤ c₁ + c₂。

**策略**：
1. 先把第一艘船**尽可能装满**（等价于特殊的 0-1 背包）
2. 剩下的装第二艘

**等价问题**：max Σ wᵢ·xᵢ，约束 Σ wᵢ·xᵢ ≤ c₁，xᵢ ∈ {0,1}

### 8.2 剪枝

```
左子树（选）：cw + w[i] ≤ c₁  → 约束剪枝
右子树（不选）：cw + r > bestw → 限界剪枝
                  ↑      ↑
              当前重量  剩余总重量
```

### 8.3 C++ 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

/**
 * 装载问题 - 回溯法
 *
 * 找到不超过 c1 的最大装载方案
 */
class LoadingBacktrack {
private:
    int n;          // 集装箱数
    double c1;      // 第一艘船容量
    vector<double> w; // 重量
    double cw;      // 当前载重量
    double bestw;   // 最优载重量
    double r;       // 剩余集装箱总重量
    vector<int> x;  // 当前解
    vector<int> bestx; // 最优解

public:
    LoadingBacktrack(int n_, double c1_, vector<double>& w_)
        : n(n_), c1(c1_), w(w_), cw(0), bestw(0), r(0) {
        x.resize(n + 1);
        bestx.resize(n + 1);
        for (int i = 1; i <= n; i++) r += w[i];
    }

    void backtrack(int i) {
        if (i > n) {                     // 到达叶子
            if (cw > bestw) {
                bestw = cw;
                for (int j = 1; j <= n; j++)
                    bestx[j] = x[j];
            }
            return;
        }

        r -= w[i];                       // 剩余重量减去当前物品

        // ===== 左子树：选第 i 个 =====
        if (cw + w[i] <= c1) {           // 约束剪枝
            x[i] = 1;
            cw += w[i];
            backtrack(i + 1);
            cw -= w[i];                  // 恢复现场
        }

        // ===== 右子树：不选第 i 个 =====
        if (cw + r > bestw) {            // 限界剪枝：还有希望吗？
            x[i] = 0;
            backtrack(i + 1);
        }

        r += w[i];                       // 恢复剩余重量
    }

    void solve() {
        backtrack(1);
        cout << "第一艘船最优载重量: " << bestw << endl;
        cout << "装入第一艘船的集装箱: ";
        for (int i = 1; i <= n; i++)
            if (bestx[i]) cout << i << " ";
        cout << endl;
    }
};

int main() {
    // 示例：n=4, c1=12, w={8,6,2,3}
    int n = 4;
    double c1 = 12;
    vector<double> w = {0, 8, 6, 2, 3};  // 下标从1开始

    LoadingBacktrack solver(n, c1, w);
    solver.solve();

    return 0;
}
/* 输出：
第一艘船最优载重量: 11
装入第一艘船的集装箱: 1 3 4
*/
```

## 九、批处理作业调度

### 9.1 问题描述

n 个作业在两台机器上处理（先 M₁ 后 M₂）。作业 i 在 M₁ 耗时为 t₁ᵢ，在 M₂ 耗时为 t₂ᵢ。

**目标**：找一个调度顺序，使**所有作业在 M₂ 上的完成时间之和**最小。

> ⚠️ 注意与第三章**流水作业调度**的区别：流水作业求**总完工时间**最小（makespan），批处理作业调度求**各作业完成时间之和**最小（sum of completion times）。

### 9.2 实例

| 作业 | M1 | M2 |
|------|-----|-----|
| 1 | 2 | 1 |
| 2 | 3 | 1 |
| 3 | 2 | 3 |

6 种排列的总完成时间和：
```
1,2,3: F₂₁+F₂₂+F₂₃ = 3+6+10 = 19
1,3,2: F₂₁+F₂₃+F₂₂ = 3+7+8  = 18 ← 最优！
2,1,3: = 20
2,3,1: = 21
3,1,2: = 19
3,2,1: = 19
```

### 9.3 递推公式

```
设 f1  = M₁ 上完成第 i 个作业的时间
设 f2[i] = M₂ 上完成第 i 个作业的时间

f1 += t₁[x[i]]                              // M₁ 累加
f2[i] = max(f2[i-1], f1) + t₂[x[i]]        // M₂ = max(前一个在M2完成, 当前在M1完成) + 当前M2耗时
f += f2[i]                                   // 累加完成时间和
```

### 9.4 C++ 代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <climits>
using namespace std;

/**
 * 批处理作业调度 - 回溯法（排列树）
 */
class FlowShopBacktrack {
private:
    int n;
    vector<vector<int>> t;   // t[i][0]=M1时间, t[i][1]=M2时间
    vector<int> x;           // 当前调度
    vector<int> bestx;       // 最优调度
    int f1;                  // M1 当前完成时间
    vector<int> f2;          // f2[i]：第 i 个作业在 M2 的完成时间
    int f;                   // 当前完成时间和
    int bestf;               // 最优完成时间和

public:
    FlowShopBacktrack(vector<vector<int>>& times)
        : n(times.size()), t(times), f1(0), f(0), bestf(INT_MAX) {
        x.resize(n);
        bestx.resize(n);
        f2.resize(n);
        for (int i = 0; i < n; i++) x[i] = i;
    }

    void backtrack(int i) {
        if (i >= n) {                    // 到达叶子
            if (f < bestf) {
                bestf = f;
                for (int j = 0; j < n; j++)
                    bestx[j] = x[j];
            }
            return;
        }

        for (int j = i; j < n; j++) {
            swap(x[i], x[j]);

            // 计算 f1 和 f2[i]
            int old_f1 = f1;
            int old_f = f;
            int old_f2i = (i > 0) ? f2[i-1] : 0;

            f1 += t[x[i]][0];                              // M1 累加
            f2[i] = ((i > 0) ? f2[i-1] : 0) > f1
                    ? f2[i-1] + t[x[i]][1]                 // M2在忙，等
                    : f1 + t[x[i]][1];                     // M2空闲，直接开始
            f += f2[i];

            // 剪枝：当前和已 ≥ 最优 → 不深入
            if (f < bestf)
                backtrack(i + 1);

            // 回溯：恢复
            f1 = old_f1;
            f = old_f;
            swap(x[i], x[j]);
        }
    }

    void solve() {
        backtrack(0);
        cout << "最小完成时间和: " << bestf << endl;
        cout << "最优调度顺序: ";
        for (int i = 0; i < n; i++)
            cout << bestx[i] + 1 << " ";
        cout << endl;
    }
};

int main() {
    // 课件示例
    vector<vector<int>> times = {
        {2, 1},  // 作业1: M1=2, M2=1
        {3, 1},  // 作业2: M1=3, M2=1
        {2, 3}   // 作业3: M1=2, M2=3
    };

    FlowShopBacktrack solver(times);
    solver.solve();

    return 0;
}
/* 输出：
最小完成时间和: 18
最优调度顺序: 1 3 2
*/
```

## 十、n皇后问题

### 10.1 问题描述

在 n×n 棋盘上放置 n 个皇后，**任意两个不能同行、同列、同斜线**。

### 10.2 解空间

- **解向量**：(x₁, x₂, …, xₙ)，x[i] 表示第 i 行的皇后放在**第 x[i] 列**
- **显约束**：x[i] ∈ {1, 2, …, n}
- **隐约束**：
  - 不同列：x[i] ≠ x[j]
  - 不同斜线：|i - j| ≠ |x[i] - x[j]|

> 斜线判断原理：主对角线（\）上"行号-列号"相等，副对角线（/）上"行号+列号"相等。所以 |i-j| = |x[i]-x[j]| 意味着同一条斜线。

### 10.3 C++ 代码

```cpp
#include <iostream>
#include <vector>
#include <cmath>
using namespace std;

/**
 * n皇后问题 - 回溯法（排列树思想）
 * 时间复杂度：O(n!)（有剪枝后实际好很多）
 */
class NQueens {
private:
    int n;
    vector<int> x;       // x[i] = 第 i 行皇后所在列
    int count;           // 解的数量

    /**
     * 检查第 k 个皇后与前面的是否冲突
     */
    bool place(int k) {
        for (int j = 1; j < k; j++) {
            // 同列 或 同斜线（|行差| == |列差|）
            if (x[j] == x[k] || abs(k - j) == abs(x[k] - x[j]))
                return false;
        }
        return true;
    }

    void backtrack(int t) {
        if (t > n) {                     // n 个皇后都放好了
            count++;
            // 输出解（n 较大时建议注释掉）
            cout << "解 " << count << ": ";
            for (int i = 1; i <= n; i++)
                cout << x[i] << " ";
            cout << endl;
            return;
        }

        for (int i = 1; i <= n; i++) {   // 尝试每一列
            x[t] = i;                    // 第 t 行皇后放第 i 列
            if (place(t))                // 不冲突才深入
                backtrack(t + 1);
        }
    }

public:
    NQueens(int n_) : n(n_), count(0) {
        x.resize(n + 1);
    }

    void solve() {
        backtrack(1);
        cout << "共 " << count << " 种解法" << endl;
    }
};

int main() {
    NQueens solver(8);  // 经典八皇后
    solver.solve();
    return 0;
}
/* 八皇后输出：
共 92 种解法
*/
```

### 10.4 四皇后剪枝过程

```
Level 1: 尝试 x[1]=1
  Level 2: x[2]=1(同列×), =2(同斜线×), =3(✓)
    Level 3: x[3]=1(同列×), =2(✓)
      Level 4: x[4]=1,2,3,4 全冲突 → 回溯！
    Level 3: x[3]=3,4 冲突
  Level 2: x[2]=4(✓)
    Level 3: x[3]=2(✓)
      Level 4: 全冲突 → 回溯
Level 1: x[1]=2
  ...最终找到解 (2,4,1,3) 和 (3,1,4,2)
```

## 十一、图的 m 着色问题

### 11.1 问题描述

给定无向连通图 G=(V,E) 和 m 种颜色。每个顶点用一种颜色着色，相邻顶点颜色必须不同。

- **m 可着色判定**：能否用 m 种颜色着色？
- **m 可着色优化**：最少需要几种颜色？（图的**色数**）

### 11.2 四色定理

任何平面图最多只需**4 种颜色**即可完成着色。

### 11.3 解空间

- **解向量**：(x₁, x₂, …, xₙ)，x[i] 表示顶点 i 的颜色编号
- **解空间树**：高 n+1 的**完全 m 叉树**（也可视为排列树的一种变形）
- 叶子数 = mⁿ

### 11.4 C++ 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

/**
 * 图的 m 着色问题 - 回溯法
 *
 * 时间复杂度：O(n·mⁿ)（最坏）
 */
class MColoring {
private:
    int n;                        // 顶点数
    int m;                        // 颜色数
    vector<vector<int>> adj;      // 邻接矩阵 adj[i][j]=1 表示 i,j 相邻
    vector<int> x;                // x[i] = 顶点 i 的颜色
    int count;                    // 着色方案数

    /**
     * 检查顶点 k 的着色是否与相邻顶点冲突
     */
    bool ok(int k) {
        for (int j = 1; j <= n; j++) {
            // 相邻 且 同色 → 冲突
            if (adj[k][j] && x[j] == x[k])
                return false;
        }
        return true;
    }

    void backtrack(int t) {
        if (t > n) {                     // 所有顶点都着色完毕
            count++;
            return;
        }

        for (int i = 1; i <= m; i++) {   // 尝试 m 种颜色
            x[t] = i;
            if (ok(t))                   // 与相邻顶点不冲突
                backtrack(t + 1);
        }
    }

public:
    MColing(vector<vector<int>>& graph, int colors)
        : adj(graph), m(colors) {
        n = adj.size() - 1;  // 下标从 1 开始
        x.resize(n + 1, 0);
        count = 0;
    }

    void solve() {
        backtrack(1);
        cout << "用 " << m << " 种颜色共有 " << count << " 种着色方案" << endl;
    }
};

int main() {
    // 5 个顶点的图（课件中的地图例子）
    int n = 5;
    vector<vector<int>> adj(n + 1, vector<int>(n + 1, 0));
    // 边：(1,2), (1,3), (2,3), (2,4), (3,4), (3,5), (4,5)
    adj[1][2] = adj[2][1] = 1;
    adj[1][3] = adj[3][1] = 1;
    adj[2][3] = adj[3][2] = 1;
    adj[2][4] = adj[4][2] = 1;
    adj[3][4] = adj[4][3] = 1;
    adj[3][5] = adj[5][3] = 1;
    adj[4][5] = adj[5][4] = 1;

    MColoring solver(adj, 3);
    solver.solve();

    return 0;
}
```

## 十二、回溯法效率分析与重排原理

### 12.1 影响效率的因素

回溯算法的效率很大程度上依赖于：

1. 产生 x[k] 的时间
2. 满足显约束的 x[k] 值的个数
3. 计算约束函数 constraint 的时间
4. 计算上界函数 bound 的时间
5. **满足约束函数和上界函数的所有 x[k] 的个数**（最重要！）

> 好的约束函数能**显著减少生成的结点数**，但可能计算量较大。需要在"生成结点数"与"约束函数计算量"之间折衷。

### 12.2 重排原理（Reorder Principle）

> 在其他条件相当的前提下，**让可取值最少的 x[i] 优先**。

```
例：搜索树的两个排列

排列 A（取值少的优先）：  排列 B（取值多的优先）：
     root                      root
    /    \                    / | \
  剪！   ...               剪！ ... ...
        / \                       /|\
       ... ...                   ...

A 的第一层剪掉 12 个三元组      B 的第一层剪掉 8 个三元组
→ 剪枝效率更高！
```

直观理解：**早点把分支少的定了，后面能剪掉的就更多。**

---

## 小结

```
回溯法 = 深度优先搜索 + 剪枝函数

剪枝函数：
├── 约束函数 Constraint → 剪去不可行解
└── 限界函数 Bound      → 剪去非最优解

两种解空间树：
├── 子集树 O(2ⁿ)    → 0-1背包、装载问题
└── 排列树 O(n!)    → TSP、作业调度、n皇后

实现方式：
├── 递归回溯（常用）
└── 迭代回溯（非递归）

关键特性：
├── 系统性：按深度优先遍历整个解空间
├── 跳跃性：剪枝跳过不可能产生解的分支
└── 空间效率：仅保留当前路径 O(n)
```
