## 一、分支限界法概述

### 1.1 核心思想

> 分支限界法常以**广度优先**或以**最小耗费（最大效益）优先**的方式搜索问题的解空间树。

**五个步骤**：

```
① 每个活结点只有一次机会成为扩展结点
② 活结点一旦成为扩展结点，就一次性生成其所有儿子结点（分支）
③ 不可行的、非最优的儿子结点被舍弃（限界）
④ 其余儿子结点加入活结点表
⑤ 从活结点表中取下一个结点成为当前扩展结点，重复
→ 直到找到所需解或活结点表为空
```

### 1.2 "分支"和"限界"的含义

| 术语 | 含义 |
|------|------|
| **分支** | 扩展结点时，一次性生成所有儿子结点 |
| **限界** | 计算每个活结点的函数值（界限），只保留有希望的结点 |

---

## 二、分支限界法 vs 回溯法

这是本章最核心的对比：

| | 回溯法 | 分支限界法 |
|---|---|---|
| **搜索方式** | **深度优先** DFS | **广度优先** BFS 或 **最小耗费优先** |
| **求解目标** | 找出**所有解**或任意解 | 找出**一个最优解** |
| **数据结构** | **栈**（递归调用栈） | **队列**（FIFO）或**优先队列**（堆） |
| **存储空间** | 小，仅存当前路径 O(n) | **大**，需维护活结点表 |
| **扩展结点** | 多次成为扩展结点（反复回溯回去） | **仅一次**成为扩展结点 |
| **结点生成** | 逐个生成儿子，立即深入 | **一次性**生成所有儿子，再选择下一个 |

**一句话记住区别**：
- 回溯 = 一根筋走到底，不行再退回来（DFS）
- 分支限界 = 广撒网，挑最有希望的先试（BFS + 优先级）

## 三、两种分支限界法

### 3.1 队列式（FIFO）分支限界法

> 按**队列先进先出**原则选下一个扩展结点。

就是 BFS 的变体——同层结点处理完才进入下一层，但跳过不可行结点。

```
活结点表：队列（Queue）
取出顺序：先进先出
```

**缺点**：盲目。每个活结点同等对待，不优先探索"更有希望"的分支。

### 3.2 优先队列式分支限界法

> 按**优先级**选最高的结点作为下一个扩展结点。

```
活结点表：优先队列（最大堆/最小堆）
优先级   ：由限界函数计算
取出顺序：优先级最高（最有希望）的优先
```

**优点**：尽快找到最优解，更早触发剪枝，效率更高。

**两种实现策略**：
1. 在每个活结点中保存从根到该结点的**完整路径**（到叶子直接得到解）
2. 仅保存**部分路径**，找到最优后通过 parent 指针**回溯**构造解

## 四、0-1背包问题（分支限界法）

### 4.1 FIFO 队列式

n=3, w={16,15,15}, v={45,25,25}, C=30

```
A(cw=0, cp=0)
生成儿子 B(16,45) 和 C(0,0)，入队
队列：[B, C]

取出B → 生成儿子 D(超重×)、E(16,45)，E入队
队列：[C, E]

取出C → 生成儿子 F(15,25)、G(0,0)，入队
队列：[E, F, G]

取出E → 生成儿子 J(超重×)、K(叶子, cv=45)，K不是叶子不入队，记录 best=45
队列：[F, G]

取出F → 生成儿子 L(叶子, cv=50>45! 更新best=50)、M(叶子, cv=25)
队列：[G]

取出G → 生成儿子 N(叶子, cv=25)、O(叶子, cv=0)
队列：[] → 结束

最优：best=50，解 x=(0,1,1)
```

> FIFO 等于 BFS，每个结点按层序处理，**等所有同层结点处理完才到叶子的 best 更新**，剪枝效果差。

### 4.2 优先队列式（按当前价值 CP）

```
优先级 = cp（当前价值），最大堆

初始：A → 生成 B(cp=45), C(cp=0)
堆：[B(45), C(0)]

取B(45) → 生成 E(cp=45)，E入堆
堆：[E(45), C(0)]

取E(45) → 生成 K(叶子, cv=45)，best=45
堆：[C(0)]

取C(0) → 生成 F(cp=25), G(cp=0)
堆：[F(25), G(0)]

取F(25) → 生成 L(叶子, cv=50>45! best=50), M(叶子, cv=25)
堆：[G(0)]

取G(0) → 生成 N(25), O(0)
结束。best=50
```

### 4.3 优先队列式（按上界 UP 更优）

```
优先级 = up（价值上界），最大堆

up 计算公式（与回溯法一致）：
  剩余容量按单位价值降序贪心装 → 得到上界值

A: up = 所有物品贪心装 = 68
生成 B(cp=45, up=68), C(cp=0, up=50)
堆：[B(68), C(50)]  ← B 上界大，优先

取B(68) → 生成 E(cp=45, up=50)
堆：[C(50), E(50)]

取C(50) → 生成 F(cp=25, up=50)
堆：[E(50), F(50)]

取E(50) → 生成 K(叶子, cv=45), best=45
堆：[F(50)]

取F(50) → up=50>best=45 → 展开
        → L(叶子,cv=50) best=50
堆：[] → 结束
```

### 4.4 C++ 代码：优先队列式分支限界法

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;

/**
 * 0-1背包 - 优先队列式分支限界法
 *
 * 活结点按"价值上界"的优先级排序（最大堆）
 * 时间复杂度：O(2ⁿ)（最坏），实际因剪枝好很多
 */
struct KpNode {
    int level;        // 当前层（第几个物品）
    double cw;        // 当前重量
    double cv;        // 当前价值
    double up;        // 价值上界（优先级）
    vector<int> x;    // 当前解（从根到当前结点的路径）

    // 最大堆：上界大的优先
    bool operator<(const KpNode& other) const {
        return up < other.up;  // STL 默认最大堆用 <
    }
};

double knapsackBB(vector<double>& w, vector<double>& v,
                  double C, int n, vector<int>& bestx) {
    // 步骤1：按单位价值降序排序（与回溯法一样）
    struct Item { double w, v, ratio; int id; };
    vector<Item> items(n + 1);
    for (int i = 1; i <= n; i++)
        items[i] = {w[i], v[i], v[i]/w[i], i};
    sort(items.begin() + 1, items.end(),
         [](const Item& a, const Item& b) { return a.ratio > b.ratio; });

    // 重新排列 w,v
    vector<double> sw(n + 1), sv(n + 1);
    for (int i = 1; i <= n; i++) {
        sw[i] = items[i].w;
        sv[i] = items[i].v;
    }

    // 步骤2：初始化
    priority_queue<KpNode> pq;
    double bestp = 0;
    vector<int> bestPath(n + 1, 0);

    // 上界函数（与回溯法完全一样）
    auto bound = [&](int i, double cw, double cv) -> double {
        double cleft = C - cw;
        double b = cv;
        while (i <= n && sw[i] <= cleft) {
            cleft -= sw[i]; b += sv[i]; i++;
        }
        if (i <= n) b += sv[i] / sw[i] * cleft;
        return b;
    };

    // 根结点
    KpNode root;
    root.level = 1; root.cw = 0; root.cv = 0;
    root.up = bound(1, 0, 0);
    root.x.resize(n + 1, 0);
    pq.push(root);

    // 步骤3：分支限界搜索
    while (!pq.empty()) {
        KpNode node = pq.top(); pq.pop();

        int i = node.level;
        if (i > n) {  // 叶子结点
            if (node.cv > bestp) {
                bestp = node.cv;
                bestPath = node.x;
            }
            continue;
        }

        // 剪枝：上界不如当前最优 → 跳过
        if (node.up <= bestp) continue;

        // ===== 左儿子：选物品 i =====
        if (node.cw + sw[i] <= C) {  // 约束函数
            KpNode left;
            left.level = i + 1;
            left.cw = node.cw + sw[i];
            left.cv = node.cv + sv[i];
            left.up = bound(i + 1, left.cw, left.cv);
            left.x = node.x;
            left.x[i] = 1;
            if (left.up > bestp) pq.push(left);
        }

        // ===== 右儿子：不选物品 i =====
        KpNode right;
        right.level = i + 1;
        right.cw = node.cw;
        right.cv = node.cv;
        right.up = bound(i + 1, right.cw, right.cv);
        right.x = node.x;
        right.x[i] = 0;
        if (right.up > bestp) pq.push(right);
    }

    // 步骤4：映射回原始物品编号
    bestx.assign(n + 1, 0);
    for (int i = 1; i <= n; i++)
        if (bestPath[i]) bestx[items[i].id] = 1;

    return bestp;
}

int main() {
    int n = 3;
    double C = 30;
    vector<double> w = {0, 16, 15, 15};
    vector<double> v = {0, 45, 25, 25};
    vector<int> bestx(n + 1);

    double ans = knapsackBB(w, v, C, n, bestx);
    cout << "最大价值: " << ans << endl;
    cout << "选中物品: ";
    for (int i = 1; i <= n; i++)
        if (bestx[i]) cout << i << " ";
    cout << endl;

    return 0;
}
```

## 五、旅行售货员问题（TSP）

### 5.1 解空间

- **排列树**，从城市 1 出发，排列 {2,3,...,n}
- 叶子数 = (n-1)!

### 5.2 优先队列式分支限界法

**优先级 = 子树费用的下界 lcost**

下界 lcost 的计算：
```
cc = 当前已走路径的费用
rcost = 剩余未访问城市的最小出边费用之和
lcost = cc + rcost
```

课件示例（4 城市）：

```
优先级 = 下界 lcost（更紧的下界）

初始：A(0) → 生成 B(30), C(6), D(4)
堆：[D(4), C(6), B(30)]          ← D 下界最小

取D(4) → 生成 J(14), K(24)
堆：[C(6), J(14), K(24)]

取C(6) → 生成 H(11), I(26)
堆：[H(11), J(14), K(24), I(26)]

取H(11) → 生成 N(25) [1,3,2,4]
堆：[J(14), K(24), N(25), I(26)]

取J(14) → 生成 P(25)
堆：[K(24), P(25), N(25), I(26)]

取K(24) → 生成 Q(59) > 25 → 丢弃

取N(25) → 已达叶子且下界=当前费用，即为最优！
           路线 1→3→2→4→1，费用=25
```

> ⚠️ 关键：优先队列式分支限界法中，**第一个成为扩展结点的叶子就是最优解**，可以直接终止！

### 5.3 C++ 代码

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <climits>
#include <algorithm>
using namespace std;

const int INF = INT_MAX / 2;

/**
 * TSP - 优先队列式分支限界法
 *
 * 优先级 = lcost（子树费用下界）
 */
struct TSPNode {
    int level;          // 当前层（已访问 city 数）
    vector<int> path;   // 当前路径
    int cc;             // 当前费用
    int lcost;          // 子树费用下界（优先级）

    bool operator<(const TSPNode& other) const {
        return lcost > other.lcost;  // 最小堆：下界小的优先
    }
};

int tspBB(vector<vector<int>>& dist, int n, vector<int>& bestPath) {
    priority_queue<TSPNode> pq;
    int bestc = INF;

    // 计算每个顶点的最小出边（用于下界计算）
    vector<int> minOut(n, INF);
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (i != j) minOut[i] = min(minOut[i], dist[i][j]);

    // 根结点：从城市 0 出发
    TSPNode root;
    root.level = 1;
    root.path.push_back(0);
    root.cc = 0;
    // 下界 = 0 + 所有城市最小出边之和
    root.lcost = 0;
    for (int i = 0; i < n; i++) root.lcost += minOut[i];

    pq.push(root);

    while (!pq.empty()) {
        TSPNode node = pq.top(); pq.pop();

        // 到达叶子（最后一个城市+回到起点）
        if (node.level == n) {
            int last = node.path.back();
            if (dist[last][0] != INF) {
                int total = node.cc + dist[last][0];
                if (total < bestc) {
                    bestc = total;
                    bestPath = node.path;
                    bestPath.push_back(0);  // 回到起点
                }
            }
            continue;
        }

        // 扩展：尝试每个未访问城市
        for (int j = 1; j < n; j++) {
            // 检查 j 是否已在路径中
            if (find(node.path.begin(), node.path.end(), j) != node.path.end())
                continue;

            int last = node.path.back();
            if (dist[last][j] == INF) continue;  // 不可达

            TSPNode child;
            child.level = node.level + 1;
            child.path = node.path;
            child.path.push_back(j);
            child.cc = node.cc + dist[last][j];

            // 计算下界：cc + 剩余顶点的最小出边之和
            child.lcost = child.cc;
            for (int k = 0; k < n; k++) {
                if (find(child.path.begin(), child.path.end(), k) == child.path.end())
                    child.lcost += minOut[k];
            }
            // 最后还要加上回到起点的最小出边
            child.lcost += minOut[j];

            if (child.lcost < bestc)  // 剪枝：下界 < 当前最优
                pq.push(child);
        }
    }

    return bestc;
}

int main() {
    vector<vector<int>> dist = {
        {INF, 30,  6,  4},
        {30,  INF, 5,  10},
        {6,   5,   INF, 20},
        {4,   10,  20, INF}
    };
    int n = 4;
    vector<int> bestPath;

    int ans = tspBB(dist, n, bestPath);
    cout << "最短路径: " << ans << endl;
    cout << "路线: ";
    for (int v : bestPath) cout << v + 1 << " ";
    cout << endl;

    return 0;
}
```

## 六、单源最短路径问题

### 6.1 优先队列式分支限界法

与 Dijkstra 贪心算法其实是同一回事——从活结点中选**当前路长最小**的优先扩展。

```
活结点表：最小堆
优先级  ：从源点到该顶点的当前最短路径长度
```

### 6.2 两种剪枝策略

**剪枝 1：下界剪枝**

一旦发现某结点的下界 ≥ 已找到的最短路径 → 剪去该子树。

```
例：已找到 s→t 路径长 8
   某结点的下界 = 10 ≥ 8 → 剪！
```

**剪枝 2：控制剪枝（优劣剪枝）**

从源点出发，两条不同路径到达**同一顶点**，路长长的那个被"控制"，可以剪去。

```
路径1: s → a → v  路长 5
路径2: s → b → v  路长 6

5 < 6 → 结点 A（路长5）控制结点 B（路长6）
→ 剪去 B 的子树（v到达后走的路都一样，但A更短）
```

### 6.3 算法核心

```cpp
while (true) {
    // 扩展当前结点 enode
    for (int j = 1; j <= n; j++) {
        // 有边可达 且 新路径 < 已知最短路径
        if (a[enode.i][j] < INF &&
            enode.length + a[enode.i][j] < dist[j]) {
            dist[j] = enode.length + a[enode.i][j];
            p[j] = enode.i;  // 记录前驱
            heap.put(new HeapNode(j, dist[j]));  // 入优先队列
        }
    }
    if (heap.isEmpty()) break;
    enode = heap.removeMin();  // 取当前最短路径的结点
}
```

这实际上就是 Dijkstra 算法的另一种表述形式，第六章不再重复给出完整 C++ 代码（Dijkstra 已在第四章详细实现过）。

## 七、装载问题

### 7.1 问题回顾

n 个集装箱，两艘船容量 c₁, c₂。先**尽可能装满第一艘**，剩余装第二艘。

**等价问题**：max Σ wᵢxᵢ，s.t. Σ wᵢxᵢ ≤ c₁

### 7.2 FIFO 队列式

关键特点：用 **-1** 标记同层结点结束。

```
while (true) {
    // 检查左儿子（选）
    if (ew + w[i] <= c) enQueue(ew + w[i], i);
    // 检查右儿子（不选）——总是可行
    enQueue(ew, i);
    // 取下一扩展结点
    ew = queue.remove();
    if (ew == -1) {  // 同层结束标记
        if (queue.isEmpty()) return bestw;
        queue.put(-1);     // 新层标记
        ew = queue.remove();
        i++;               // 进入下一层
    }
}
```

**enQueue 算法**：

```java
void enQueue(int wt, int i) {
    if (i == n) {              // 叶子结点
        if (wt > bestw) bestw = wt;  // 更新最优
    } else {                   // 内部结点
        queue.put(wt);         // 入活结点队列
    }
}
```

叶子结点**不入队**，直接检查是否更新最优值。

### 7.3 改进：加入限界剪枝

**右子树剪枝条件**：`ew + r > bestw`

```
r = 剩余集装箱总重量
如果当前重量 + 剩余全部重量 ≤ bestw → 选右子树（不装当前箱子）
  就算后面全装也无法超过 bestw → 剪！
```

**提前更新 bestw**：每次进入左子树时就更新 bestw（不等叶子），让右子树剪枝尽早生效。

### 7.4 优先队列式

**优先级**：`ew + r`（当前重量 + 剩余总重量）→ 即该子树能达到的最大重量

```
活结点表：最大堆（优先级大的优先）
优先级 = ew + r

特点：一旦有一个叶子成为当前扩展结点 → 它就是最优解 → 立即终止！
（因为叶子的优先级 = 它的实际重量，而堆中所有结点优先级都不超过它）
```

### 7.5 构造最优解

通过在每个结点处保存**父结点指针**和**左右儿子标志**：

```java
class QNode {
    QNode parent;        // 父结点
    boolean leftChild;   // true=左儿子(选了), false=右儿子(没选)
    int weight;          // 结点对应的载重量
}
```

找到最优叶子后，沿 parent 链回溯到根，得到每个物品的选取情况。

```java
// 回溯构造最优解
for (int j = n - 1; j > 0; j--) {
    bestx[j] = bestE.leftChild ? 1 : 0;
    bestE = bestE.parent;
}
```

### 7.6 C++ 代码：优先队列式

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

/**
 * 装载问题 - 优先队列式分支限界法
 *
 * 优先级 = ew + r（当前 + 剩余）
 * 时间复杂度：O(2ⁿ)
 */
struct LoadNode {
    int level;       // 层数
    int ew;          // 当前重量
    int r;           // 剩余重量
    int priority;    // ew + r（优先级）
    LoadNode* parent;
    bool leftChild;

    bool operator<(const LoadNode& other) const {
        return priority < other.priority;  // 最大堆
    }
};

double maxLoading(vector<double>& w, double c, int n, vector<int>& bestx) {
    priority_queue<LoadNode> pq;
    double bestw = 0;

    // 计算总重量
    double total = 0;
    for (int i = 1; i <= n; i++) total += w[i];

    // 根结点
    LoadNode* root = new LoadNode{1, 0, (int)total, (int)total, nullptr, false};
    pq.push(*root);

    while (!pq.empty()) {
        LoadNode node = pq.top(); pq.pop();

        int i = node.level;
        if (i > n) {  // 叶子 → 最优！（优先队列式特性）
            bestw = node.ew;
            // 回溯构造解
            LoadNode* cur = &node;
            for (int j = n; j >= 1; j--) {
                bestx[j] = cur->leftChild ? 1 : 0;
                cur = cur->parent;
            }
            break;
        }

        // ===== 左儿子：选 =====
        if (node.ew + w[i] <= c) {
            LoadNode left;
            left.level = i + 1;
            left.ew = node.ew + w[i];
            left.r = node.r - w[i];
            left.priority = left.ew + left.r;
            left.parent = &node;
            left.leftChild = true;
            pq.push(left);
            if (left.ew > bestw) bestw = left.ew;  // 提前更新
        }

        // ===== 右儿子：不选（限界剪枝）=====
        if (node.ew + node.r - w[i] > bestw) {
            LoadNode right;
            right.level = i + 1;
            right.ew = node.ew;
            right.r = node.r - w[i];
            right.priority = right.ew + right.r;
            right.parent = &node;
            right.leftChild = false;
            pq.push(right);
        }
    }

    return bestw;
}

int main() {
    int n = 4;
    double c = 12;
    vector<double> w = {0, 8, 6, 2, 3};
    vector<int> bestx(n + 1, 0);

    double ans = maxLoading(w, c, n, bestx);
    cout << "最优载重量: " << ans << endl;
    cout << "装入集装箱: ";
    for (int i = 1; i <= n; i++)
        if (bestx[i]) cout << i << " ";
    cout << endl;

    return 0;
}
```

## 八、批处理作业调度

### 8.1 问题回顾（同第五章）

n 个作业，两台机器（先 M₁ 后 M₂），求调度使**完成时间和**最小。

### 8.2 限界函数（本章重点）

在结点 E（已排好前 r 个作业 M）处，子树中叶结点的完成时间和的下界：

```
设 M 中作业在 M₂ 完成时间和为 ΣF₂ᵢ

S₁ = 剩余作业在 M₁ 上的最小可能等待 + 各作业 M₂ 处理时间
S₂ = 剩余作业在 M₂ 上以某种顺序的最小可能完成时间和

下界 = ΣF₂ᵢ + max(S₁, S₂)
```

### 8.3 算法步骤

```
活结点表：最小堆
优先级 = bb（完成时间和的下界），bb 小的优先

while 循环：
  if enode.s == n（叶子）
      if enode.sf2 < bestc → 更新最优
  else
      对每个未排列的作业（排列树 swap 模式）：
          计算 bb = bound(node)
          if bb < bestc → 入优先队列
```

### 8.4 C++ 代码

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
#include <climits>
using namespace std;

/**
 * 批处理作业调度 - 优先队列式分支限界法
 *
 * 优先级 = bb（完成时间和的下界），最小堆
 */
struct JobNode {
    vector<int> x;     // 当前调度（前 s 个已确定）
    int s;             // 已安排的作业数
    int f1;            // M₁ 最后完成时间
    int f2;            // M₂ 最后完成时间
    int sf2;           // M₂ 完成时间和
    int bb;            // 完成时间和的下界（优先级）

    bool operator<(const JobNode& other) const {
        return bb > other.bb;  // 最小堆：下界小的优先
    }
};

int flowShopBB(vector<vector<int>>& t, int n,
               vector<int>& bestx) {
    priority_queue<JobNode> pq;
    int bestc = INT_MAX;

    // 限界函数（课件公式）
    auto bound = [&](JobNode& node) -> int {
        // 已安排作业在 M₂ 的完成时间和
        int sumF2 = node.sf2;
        // 剩余作业在 M₁ 上的最小完成时间增量
        // （此处为简化版本，课件中更复杂）
        int s1 = 0, s2 = 0;
        for (int i = node.s; i < n; i++) {
            s1 += t[node.x[i]][0];
            s2 += t[node.x[i]][1];
        }
        return sumF2 + max(s1, s2);
    };

    // 根结点
    JobNode root;
    root.x.resize(n);
    for (int i = 0; i < n; i++) root.x[i] = i;
    root.s = 0; root.f1 = 0; root.f2 = 0; root.sf2 = 0;
    root.bb = bound(root);
    pq.push(root);

    while (!pq.empty()) {
        JobNode node = pq.top(); pq.pop();

        if (node.bb >= bestc) continue;  // 剪枝

        if (node.s == n) {  // 叶子
            if (node.sf2 < bestc) {
                bestc = node.sf2;
                bestx = node.x;
            }
            continue;
        }

        // 扩展儿子（排列树 swap 模式）
        for (int i = node.s; i < n; i++) {
            swap(node.x[node.s], node.x[i]);

            // 计算新结点的 f1, f2, sf2
            int new_f1 = node.f1 + t[node.x[node.s]][0];
            int new_f2 = max(node.f2, new_f1) + t[node.x[node.s]][1];
            int new_sf2 = node.sf2 + new_f2;

            JobNode child;
            child.x = node.x;
            child.s = node.s + 1;
            child.f1 = new_f1;
            child.f2 = new_f2;
            child.sf2 = new_sf2;
            child.bb = bound(child);

            if (child.bb < bestc) pq.push(child);

            swap(node.x[node.s], node.x[i]);  // 恢复
        }
    }

    return bestc;
}

int main() {
    vector<vector<int>> t = {
        {2, 1}, {3, 1}, {2, 3}
    };
    int n = 3;
    vector<int> bestx;

    int ans = flowShopBB(t, n, bestx);
    cout << "最小完成时间和: " << ans << endl;
    cout << "调度顺序: ";
    for (int x : bestx) cout << x + 1 << " ";
    cout << endl;

    return 0;
}
```

## 九、小结与对比总结

### 9.1 分支限界法求解步骤总结

```
1. 定义解空间
2. 确定解空间树结构（子集树 or 排列树）
3. 按 BFS 方式搜索：
   a) 确定限界函数，计算目标函数的界
   b) 扩展当前结点 → 生成所有儿子
   c) 儿子超出界 → 丢弃，否则 → 入活结点表
   d) 从活结点表中选最优优先级结点 → 继续扩展
4. 重复直到找到最优解
```

### 9.2 回溯 vs 分支限界 最终对比

| | 回溯法 | 分支限界法 |
|---|---|---|
| **搜索策略** | 深度优先 DFS | 广度优先 BFS / 最优优先 |
| **数据结构** | 栈 | 队列 / 优先队列 |
| **空间** | O(n) 小 | 活结点表，可能很大 |
| **每次生成** | 一个儿子，立即深入 | 所有儿子，然后选最佳 |
| **结点机会** | 可多次成为扩展结点 | 仅一次 |
| **目标** | 找出所有解 | 找出最优解 |
| **典型问题** | n皇后、图着色 | 0-1背包、TSP、装载 |

### 9.3 五种算法全景对比

```
                        求解方式
                        /      \
                  精确最优      近似/启发式
                 /        \
          自底向上填表    搜索+剪枝
          (DP)          /        \
                   深度优先    广度/最优优先
                   (回溯法)   (分支限界法)

贪心算法 — 自顶向下，局部最优，不回头
```

| 算法 | 搜索方式 | 解空间 | 时间复杂度 | 应用 |
|------|----------|--------|------------|------|
| **DP** | 自底向上填表 | 所有子问题 | 多项式 O(n²~n³) | 最优子结构+重叠子问题 |
| **贪心** | 自顶向下，一条路 | 局部最优 | O(n log n) | 贪心选择性质 |
| **回溯** | DFS + 剪枝 | 子集树/排列树 | O(2ⁿ) / O(n!) | 所有解 / 最优解 |
| **分支限界** | BFS/优先 + 剪枝 | 子集树/排列树 | O(2ⁿ) / O(n!) | 最优解 |
